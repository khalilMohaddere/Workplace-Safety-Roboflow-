# Workplace-Safety-Roboflow-
Workplace Safety is an AI-powered system designed to monitor working environments, detect potential hazards, and prevent occupational accidents using Computer Vision, YOLOv8, PyTorch, and OpenCV. It identifies safety violations, detects missing PPE, monitors restricted areas, and helps improve worker protection through real-time surveillance.
